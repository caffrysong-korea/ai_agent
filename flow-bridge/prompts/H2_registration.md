# H2 — 에이전트 등록 + 위임 실호출 확인

H1 완료 후, **opencode를 재시작한 다음** 붙여넣는다. 실제 작업은 하지 않고 호출 통로만 확인한다.

---

flow-bridge 에이전트 등록과 위임 통로를 확인하자. **실제 분석 작업은 하지 마.** 호출이 되는지만 본다.

1. 지금 너에게 보이는 도구 목록을 나열하고, sub-agent 위임 도구(`task` 등)가 있는지, 허용되는 subagent_type 값이 무엇인지 알려줘.
2. 아래 3개를 **실제로 호출**해. 각 에이전트에게는 "너의 이름과 역할을 한 줄로 답하고 끝내" 라고만 시켜.
   - flow-mapper
   - card-curator
   - pnr-rundori (기존 DELTA 에이전트)
3. 호출에 실패하면 **네가 그 에이전트 역할을 대신하지 마 (모사 금지).** 실패 메시지를 그대로 적어.
4. 성공한 호출 문법을 두 SKILL.md의 "위임 규약"에 있는 `task(subagent_type=...)` 자리에 반영할지 계획만 보여줘. (수정은 내 승인 후)

보고 형식:
```
[위임 도구] 이름 / 허용 subagent_type
[flow-mapper] 성공/실패 (실패 메시지)
[card-curator] 성공/실패
[pnr-rundori] 성공/실패
[반영 계획] 한 줄
```
